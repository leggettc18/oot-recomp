# Ocarina of Time Recompiled

Very early stages. Not intended to compete with or replace Zelda64Recompiled, just something
I wanted to do in my own time. Build steps are similar to other recomps, including
Zelda64Recompiled. More detail will be filled in later.

At the time of writing, the game boots, but that's about it. Several icons/assets/theming are
missing in the UI, there are no enhancements other than the interpolation that happens out of the
box with recomps/rt64, and the game crashes when you try to pause. This will likely be fixed
before too long, just need to figure out a few patches.

I used Zelda64Recompiled and BanjoRecompiled as "templates" so to speak, favoring BanjoRecompiled's
structure since it uses the current RecompFrontend and such, unlike Zelda64Recompiled.
